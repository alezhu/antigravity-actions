# Навык: Безопасная отправка изменений (Git Push)

Когда вызывается этот навык, **в первую очередь (первой строкой ответа)** выведи:
`### ⚡ Executing command: /push`

## Инструкции

1. **Проверка текущей ветки и неотправленных коммитов**:
   - Определи текущую ветку через `git branch --show-current` или `git status`.
   - Проверь неотправленные коммиты через `git log @{u}..HEAD --oneline` (или `git cherry -v`).

2. **Проверка безопасности перед отправкой**:
   - Убедись, что нет случайных изменений, забытых файлов или конфликтов.
   - Проверь удаленный репозиторий (`git remote -v`).

3. **Выполнение Push**:
   - Выполни `git push` (или `git push -u origin <branch>` при первой отправке новой ветки).
   - Предоставь краткий и понятный отчет об отправленных коммитах.
   - Ответ формируй на русском языке (или языке, запрошенном пользователем).
