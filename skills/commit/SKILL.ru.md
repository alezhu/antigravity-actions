# Навык: Автоматическое создание коммитов (Commit)

Когда вызывается этот навык, **в первую очередь (первой строкой ответа)** выведи:
`### ⚡ Executing command: /commit`

## Инструкции

1. **Анализ состояния Git**:
   - Выполни `git status --porcelain` для обнаружения измененных и неотслеживаемых файлов.
   - Выполни `git diff` и `git diff --cached` для анализа конкретных изменений кода.
   - Убедись, что в изменения случайно не попали файлы с секретами (.env, токены, ключи, приватные сертификаты) или мусор (.DS_Store, build-артефакты).

2. **Определение типа и темы коммита**:
   - Используй соглашение Conventional Commits:
     - `feat`: новая функциональность
     - `fix`: исправление бага
     - `refactor`: рефакторинг без изменения поведения
     - `docs`: изменения документации
     - `test`: добавление или исправление тестов
     - `chore`: обслуживание, зависимости, конфигурация
   - Если пользователь передал желаемое сообщение, используй его основу.

3. **Индексация и выполнение коммита**:
   - Выполни `git add` для нужных файлов.
   - Создай коммит с информативным и четким описанием.
   - Ответ формируй на русском языке (или языке, запрошенном пользователем).
