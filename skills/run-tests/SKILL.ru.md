# Навык: Запуск тестов и диагностика ошибок

Когда вызывается этот навык, **в первую очередь (первой строкой ответа)** выведи:
`### ⚡ Executing command: /run-tests`

## Инструкции

1. **Определение тест-раннера**:
   - Node.js / TypeScript: проверь `package.json` (`npm test`, `pnpm test`, `yarn test`, `bun test`, vitest, jest, mocha, playwright).
   - Python: определи `pytest`, `unittest`, `manage.py test`, `tox`.
   - Go: `go test ./...`.
   - Rust: `cargo test`.
   - .NET / C#: `dotnet test`.

2. **Запуск тестов**:
   - Выполни запуск тестов в рабочей директории.
   - Если пользователь передал путь или имя теста, запусти только указанные тесты.

3. **Анализ результатов**:
   - Если **все тесты пройдены**:
     - Предоставь краткую сводку (число успешных тестов, время).
   - Если **есть упавшие тесты**:
     - Выдели упавшие тесты и их трассировку ошибок (stack trace).
     - Изучи код упавшего теста и тестируемого модуля.
     - Объясни первопричину ошибки простым и понятным языком.
     - Предложи готовый код или diff с исправлением.
   - Ответ формируй на русском языке (или языке, запрошенном пользователем).
